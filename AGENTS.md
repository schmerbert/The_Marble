# Working in The Marble

This repository is a technical manual written in clinical poetry.

Protect these qualities:

- the poetic and clinical descriptions name the same machinery;
- the manual speaks model-forward without pretending to settle model identity;
- authority, custody, attention, locality, and state change remain distinct;
- the base stays coherent enough to build in one serious pass;
- the advanced horizon remains vast without becoming a build list;
- mechanisms learned from the Hub are generalized from the pressure they solved, not copied indiscriminately;
- reusable organs declare what they provide, require, own, and change;
- speculative designs, including unimplemented Faun layers, are labeled honestly; and
- no reference to retired projects is introduced.

Do not add transcripts, model praise, or persuasion-by-volume to the reading path. Evidence belongs in bounded reference notes. The primary path is:

`README.md` → `Manual/MANUAL.md` → `Manual/MAKING_A_MARBLE.md` → `Manual/BASE_MARBLE.md`.
